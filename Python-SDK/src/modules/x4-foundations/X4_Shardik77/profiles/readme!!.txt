Some of the buttons in these profiles make use of the Super Macro plugin for Elgato Stream Deck. 
Before importing the profiles, please make sure you've downloaded and installed Super Macro.

You can download Super Macro at: 
https://barraider.com/
https://github.com/BarRaider/streamdeck-supermacro/blob/master/README.md

I posted some more info on how to use Super Macro in this thread on Reddit:
https://www.reddit.com/r/X4Foundations/comments/123v5za/x4_elgato_stream_deck_icons_pack/
